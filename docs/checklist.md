# Чек-лист вычитки перед выходом

- [ ] Прочитать вслух по таймеру: полная версия укладывается в 8 минут, короткая — в 2.
- [ ] Проверить ударения: «декабря́», «фонаря́», «сполна́», «щёлкать» — не съезжать на бытовую речь.
- [ ] Канонические цитаты — дословно, без «улучшений».
- [ ] Вторая девица не перебивает Первую по смыслу: эксклюзив ≠ акция.
- [ ] На сцене реально открывается окно адвента и звенит «касса».
- [ ] Три ленты чеков связаны в узел до эпилога, а не во время него.
- [ ] Прозаические вставки («речитатив») отбиты интонацией от стиха.
- [ ] Ни одной строки, за которую неловко перед детьми в зале.
- [ ] Фамилия «Пушкин» и «34 года» звучат без ошибок; «Любовь побеждает» — в финале.
